# Aplikasi Hand Over Mobil Tangki & AMT - Pertamina

Aplikasi mobile-first untuk proses serah terima (Hand Over) Mobil Tangki (MT) dan Awak Mobil Tangki (AMT) Pertamina sesuai dengan SOP keselamatan HSSE.

## ?? Fitur Utama
1. **Header Mobile Status Bar**: Tampilan modern menyerupai antarmuka smartphone dengan indikator status bar dan navigasi.
2. **Identitas Dinamis**:
   - Nomor Polisi MT dapat diketik manual bebas dengan tombol Reset instan.
   - Pilihan Shift kerja berbasis Dropdown interaktif (Shift 1, Shift 2, Shift 3).
3. **Checklist Interaktif**:
   - Bagian A: 18 Item Perlengkapan Mobil Tangki (Rem, Ban, Wiper, APAR, STNK, Spill Kit, dll).
   - Bagian B: 10 Item Perlengkapan AMT (SIM, Seragam, Safety Shoes/Helm, ID Card, dll).
   - Animasi transisi akordion halus dengan indikator panah dinamis (arah kanan saat tertutup, turun saat dibuka).
4. **Formulir ODO Meter & Catatan (Bagian C)**:
   - Pencatatan ODO Awal dan ODO Akhir.
   - Pilihan Kategori Evaluasi: *Normal / Sesuai*, *Minor (Catat)*, dan *Mayor (Stop / Maintenance)*.
   - Catatan temuan lapangan.
   - Verifikasi tanda tangan digital 3 pihak (Pengemudi AMT, Pengawas, Petugas HSSE).
5. **Alur Evaluasi Sesuai SOP**:
   - **Normal / Minor**: Mengarah ke halaman serah terima sukses dengan rincian laik operasi.
   - **Mayor**: Mengarah ke tiket perbaikan (*maintenance blocked*) untuk penanganan armada tangki.

## ?? Cara Unduh & Pasang di Android (.apk)
1. Buka tab **[Releases](https://github.com/kangharfebrin-dot/handover/releases)** di repositori GitHub ini.
2. Unduh file `.apk` rilis terbaru (misal: `HandOver-v1.0.x.apk`).
3. Buka file `.apk` tersebut di smartphone Android Anda dan pilih **Install**.
